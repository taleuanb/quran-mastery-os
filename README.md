# 📖 Quran Mastery OS

Système de gestion hybride (React / Notion) pour l'apprentissage du Coran basé sur la mémorisation active et la répétition espacée (SRI).

## 🚀 Démarrage local

1. Installer les dépendances : `npm install`
2. Lancer le serveur : `npm run dev`

## 🛠️ Architecture
- **Frontend** : React + Vite + Tailwind CSS
- **Backend / DB** : Notion API (via Vercel Serverless Functions)
- **Hébergement** : Vercel
